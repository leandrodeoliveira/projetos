# Pesquisa de Satisfação - TudoWeb

Projeto desenvolvido em Python para a atividade da Agenda 08 da disciplina Desenvolvimento de Sistemas I.

## Objetivo

Desenvolver um programa utilizando estruturas de repetição e decisão para realizar uma pesquisa de satisfação com clientes da empresa TudoWeb.

## Funcionalidades

O sistema realiza o cadastro de 50 entrevistados, solicitando:

- Nome
- Idade
- Opinião sobre o atendimento

## Opções da Pesquisa

- 1 - EXCELENTE
- 2 - BOM
- 3 - RUIM

## Resultado

Ao final da pesquisa, o sistema apresenta:

- Quantidade de respostas EXCELENTE
- Quantidade de respostas RUIM

## Estruturas Utilizadas

- Estrutura de repetição `for`
- Estrutura de decisão `if` e `elif`
- Variáveis e contadores
- Entrada e saída de dados

## Tecnologias Utilizadas

- Python 3
- Visual Studio Code
